Python Code Difficulty Classifier

Project Description

Python Code Difficulty Classifier is a Python-based project that classifies programming problems into three difficulty levels: Easy, Medium, and Hard.

The system analyzes the keywords in a given programming question and identifies its difficulty level. It also displays a reason for the classification.

Technologies Used

- Python
- Python IDLE

Project Features

- Accepts Python programming questions from users.
- Identifies basic programming concepts.
- Detects intermediate programming concepts.
- Recognizes advanced programming concepts.
- Classifies questions into Easy, Medium, and Hard.
- Displays the classification result with a reason.
- Allows users to enter multiple questions.

Classification Levels

- Easy: Basic concepts such as printing, variables, input, and addition.
- Medium: Intermediate concepts such as loops, functions, lists, and dictionaries.
- Hard: Advanced concepts such as recursion, inheritance, algorithms, and dynamic programming.

Project File

- "main.py" – Contains the complete Python program.

How to Run

1. Install Python on your computer.
2. Open the project in Python IDLE.
3. Run the "main.py" file.
4. Enter a Python programming question.
5. View the difficulty level and classification reason.

Objective

The main objective of this project is to provide a simple way to identify the difficulty level of Python programming questions.

Conclusion

The Python Code Difficulty Classifier demonstrates how Python can be used to analyze programming questions and categorize them into different difficulty levels using keyword-based analysis.
